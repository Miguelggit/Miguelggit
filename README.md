🏠 Vitrine de Imóveis - Raquel Marinho Imóveis

Este projeto foi desenvolvido para atender uma necessidade real da corretora Raquel Marinho Imóveis, que enfrentava dificuldades para divulgar imóveis com agenciamento exclusivo em portais imobiliários de terceiros.

Para solucionar esse problema, foi criada uma Vitrine de Imóveis própria, permitindo que imóveis exclusivos da corretora fossem divulgados em uma plataforma personalizada, independente de integrações com outros portais.

Além da área pública destinada aos clientes, onde é possível visualizar os imóveis disponíveis, o sistema conta com um painel administrativo completo, desenvolvido para que a própria corretora possa realizar o gerenciamento de imóveis, imagens e informações cadastrais de forma autônoma.
